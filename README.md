### 🏙️ Nagar Sheba: City Complaint & Service Request Platform
> **Flagship.** Report it. Track it. See it fixed.

<table>
<tr>
<td width="55%" valign="top">

- 👥 **3 roles** (Citizen, Staff, Admin) enforced at route, layout and UI level, plus a DB re-check on every API request
- 🔐 JWT with **rotating refresh tokens**, Google Sign-In, email OTP, single-flight token refresh on the client
- 💳 **SSLCommerz + bKash** with server-side verification, idempotent callbacks, auto-refunds and **PDF receipts**
- ⏱️ Request lifecycle with **SLA deadlines, overdue flagging** and auto-close via a 15-minute cron job
- 🧭 4-step request wizard, geolocation, live map preview, upload progress
- 📊 Admin **Recharts analytics**, CSV export, full **audit log**
- 🌗 Dark mode, URL-synced filters, skeleton loaders, SEO + ISR

**Stack:** `Next.js 16` · `React 19` · `TypeScript` · `Tailwind v4` · `TanStack Query/Form` · `Express 5` · `Prisma 7` · `PostgreSQL` · `Redis` · `Zod` · `Cloudinary`

## 🧠 How I Build

| Principle | In practice |
|---|---|
| 🧱 **Modular architecture** | `route → validation → controller → service` on the backend; `api → hooks → components` on the frontend |
| 🔒 **Security first** | httpOnly cookies, bcrypt, rate limiting, server-side payment verification, open-redirect protection |
| ✅ **Validated end to end** | Zod schemas on both client and server so rules never drift |
| ⚡ **Smooth UX** | Skeletons, optimistic updates, URL-synced state, error boundaries, accessibility basics |
| 🚢 **Shipped, not just built** | Everything deployed on Render, Vercel or Netlify with live demos |
